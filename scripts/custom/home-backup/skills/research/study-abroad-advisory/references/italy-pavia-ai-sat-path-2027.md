## ⚠️ CRITICAL PROCESS NOTES (CORRECTING PRIOR SESSION ASSUMPTIONS)

### 1. IELTS is NOT required for Pavia AI, Sapienza ACS-AI, or Trento CS
- **Pavia AI** explicitly states this 3 times in official docs
- **Sapienza ACS-AI** requires only B2 self-declaration (test optional, no certificate at admission)
- **Trento CS** requires B2 by end of Year 1 (not at admission)
- The earlier reference file ("IELTS is unavoidable for English-medium bachelor's") was **overgeneralised** — it does not apply to these three programs.

### 2. The "best DSU for low-income" ranking changed
- **Previous:** ER.GO (max €7,171) was top
- **Now:** EDiSU Pavia (max €8,274) is top
- For a 60.2% / Hindi medium / ₹60k applicant, Pavia AI is the new top recommendation.

### 3. SAT is the answer for low-income Hindi-medium applicants
- Avoids IELTS entirely (₹17,000 saved)
- College Board India Scholars = 90% fee waiver (₹12,300 → ₹1,230)
- Standardized test = 12th %age NOT a factor (only SAT score matters)
- Multiple test dates per year (Oct, Dec, Mar, May, Jun)

### 4. Spouse-during-study rule still applies
- Italy student permit does NOT allow spouse reunification during study (same as Hungary/Singapore, already covered in skill)
- Both partners must apply as independent students
